# Experiment 9 - Interactive 3D Scene Using Unity

## Aim
Create a simple interactive 3D scene using Unity.

## Technologies
- Unity 6.3 LTS
- C#
- Universal Render Pipeline (URP)

## 3D Objects
1. Cerulean Blue Cube
2. Jet Black Capsule
3. Neon Rose Pyramid

## Features
- Interactive object selection
- Object movement
- Object rotation
- Scale up and scale down
- Reset object size
- Reset selected object
- Keyboard-controlled camera rotation and zoom
- Custom lighting and 3D environment

## Colour Palette
- Jet Black
- Cerulean Blue
- Neon Rose

## How to Run
1. Open Unity Hub.
2. Select Add Project from Disk.
3. Select this project folder.
4. Open Assets/Scenes/Experiment9Scene.unity.
5. Press Play.

## Implementation
Created using Unity, C# and Universal Render Pipeline.
