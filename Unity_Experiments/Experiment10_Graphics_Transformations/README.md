# Experiment 10 - Geometric Transformations Using Unity

## Aim
Implement geometric transformations using homogeneous coordinates and transformation matrices.

## Technologies
- Unity 6.3 LTS
- C#
- Universal Render Pipeline

## Transformations
- Translation
- Rotation
- Rotation about an arbitrary pivot
- Non-uniform scaling
- Reflection
- Shearing
- Composite transformations
- Continuous rotation

## Additional Features
- Keyboard-controlled camera rotation and zoom
- Object rotation
- Perspective and orthographic projection
- Viewport mapping

## Colour Palette
- Jet Black
- Cerulean Blue
- Neon Rose

## How to Run
1. Open Unity Hub.
2. Select Add Project from Disk.
3. Select this project folder.
4. Open Assets/Scenes/Experiment10Scene.unity.
5. Press Play.

## Implementation
Implemented using Unity and C#.
