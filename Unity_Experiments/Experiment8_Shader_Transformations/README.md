# Experiment 8 - 2D Geometric Transformations

## Aim
Implement fundamental 2D geometric transformations using homogeneous coordinates and transformation matrices.

## Technologies
- Unity 6.3 LTS
- C#
- HLSL / ShaderLab
- Universal Render Pipeline (URP)

## Transformations
1. Translation
2. Rotation
3. Rotation about an arbitrary pivot
4. Non-uniform scaling
5. Reflection about X-axis
6. Reflection about y = x
7. Shearing
8. Composite transformations
9. Continuous rotation animation

## Colour Palette
- Jet Black
- Cerulean Blue
- Neon Rose

## How to Run
1. Open Unity Hub.
2. Select Add Project from Disk.
3. Select this project folder.
4. Open Assets/Scenes/Experiment8Scene.unity.
5. Press Play.

## Implementation Note
This is a Unity URP implementation using C# and HLSL/ShaderLab. It is not a native OpenGL/GLSL implementation.
